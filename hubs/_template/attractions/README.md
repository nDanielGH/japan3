# Attractions

Places and activities to visit while based at this hub. Triage state is encoded by folder — move a file to change its status.

## Triage folders

| Folder | Purpose |
|--------|---------|
| **`inbox/`** | Raw ideas, unreviewed. Low bar to add; no decision yet. |
| **`shortlisted/`** | Looked into and plausible, but not committed. Active comparison set. |
| **`selected/`** | Confirmed — we will visit this while based at this hub. |
| **`skipped/`** | Ruled out — file must record `skip_reason` in frontmatter. |

## Triage flow

`inbox` → `shortlisted` → `selected` or `skipped`

Move the file between folders; no tags or spreadsheet needed.

## Adding an attraction

Copy `_template.md` into `inbox/` and fill in what you know. Time is **not** allocated here — scheduling happens in `itinerary/` at the hub level.
