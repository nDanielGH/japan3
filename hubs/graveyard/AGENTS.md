# Rejected hubs

This directory contains hub candidates that were rejected. Keep each rejected
hub directory intact so its research and context remain available.

- Move rejected hubs here rather than deleting them.
- Do not include these folders in the root README Status `hubs:` list.
- Do not schedule attractions from graveyard hubs.
- A later reconsideration should move the complete hub directory back under
  `hubs/` and update the root Status block.
